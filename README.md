# Curso EBAC Frontend

Reuniao dos projetos de frontend e das atividades de testes do curso EBAC.

## Estrutura

- `cypress/`: exercicios e testes end-to-end ja existentes no repositorio.
- `projetos/minhas-tarefas/`: aplicacao React e TypeScript organizada como
  projeto independente, com seu proprio `package.json`.

## Como executar o projeto de tarefas

```bash
cd projetos/minhas-tarefas
npm install
npm run dev
```

Consulte [a origem do projeto de tarefas](projetos/minhas-tarefas/ORIGEM.md)
para manter a atribuicao correta do fork original.
